Filter Girl Reposter

Filter Girl Reposter is a small personal tool used only by the owner of the YouTube channel The Filter Girl (@filtergirlmain). It is not offered or distributed to anyone else.

What it does

  • Downloads the channel owner's own public TikTok videos.
  • Uploads them to the owner's own YouTube channel as Shorts, set to private with a scheduled publish time.
  • Reads the owner's own channel (its video list, privacy and processing status, tags and view counts) so it never uploads the same video twice and can report which titles performed well.

Google data it uses

When the owner signs in with Google, the tool asks for two permissions: manage your YouTube videos (youtube.upload) to upload videos, and view your YouTube account (youtube.readonly) to read the channel's own videos. It uses them only for the purposes above.
