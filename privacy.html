Privacy Policy

Last updated: November 11, 2026

Filter Girl Reposter ("the tool") is a personal automation used only by the owner of the YouTube channel The Filter Girl (@filtergirlmain). This policy explains what the tool does with Google user data.

Whose data

The only Google account the tool accesses is the channel owner's own account. It is not offered to other users and does not collect data about viewers or anyone else.

What Google data is accessed and why

  • youtube.upload: to upload the owner's own videos to the owner's channel as private videos with a scheduled publish time.
  • youtube.readonly: to read the owner's channel information and the owner's uploaded videos (titles, tags, privacy/processing status, publish times and view counts). This is used to confirm the right channel is connected, avoid uploading the same video twice, detect failed or blocked uploads, and list which past titles performed well.

How data is stored

  • The tool runs on GitHub Actions (GitHub's servers) in the owner's private GitHub repository. Each run uses a fresh temporary server that GitHub discards when the run ends.
  • The Google sign-in credentials (OAuth client ID, client secret and refresh token) are stored as encrypted GitHub Actions secrets in that private repository, and in a private file on the owner's computer. They are never published or written to logs.
  • The private repository also keeps a list of the owner's TikTok video IDs and captions with the matching YouTube video IDs, titles, schedule times and upload status, and occasional reports of the channel's own video titles and view counts.
  • Each run's log (video IDs, titles and upload status, never credentials) is kept by GitHub in the private repository for up to 90 days.
  • Video files are downloaded temporarily to process an upload and deleted afterwards.

Sharing

Google user data is not sold, shared with, or transferred to anyone. It is not used for advertising, and it is not used to train AI or machine-learning models. The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Removing access and deleting data

The owner can revoke the tool's access at any time at myaccount.google.com/permissions. Deleting the GitHub secrets, the local credential files, and the private repository (which includes its run logs) removes all stored data.
